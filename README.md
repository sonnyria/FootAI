
# ⚽ FootFast PRO - Neural Football Predictor v4.4

FootFast PRO est une plateforme d'analyse prédictive utilisant la puissance de l'IA générative (Gemini 3 Flash & Mistral 7B) pour anticiper les résultats de football.

## ✨ Fonctionnalités Clés
- **IA Multicouche** : Analyse combinée du web (Google Search Grounding) et de statistiques historiques.
- **Verdict Neural** : Probabilités 1N2 détaillées, score exact prédit et analyse textuelle contextuelle.
- **Indice de Confiance** : Calcul du degré de certitude (0-100%) basé sur la fiabilité des données sources.
- **Système de Secours** : Bascule automatique sur Mistral 7B (Hugging Face) en cas de saturation des quotas Gemini.

## 🛠 Configuration
L'application nécessite au moins une clé API Google Gemini pour fonctionner.
1. **Google AI Studio** : Indispensable pour la recherche en temps réel.
2. **Hugging Face** : Recommandé comme solution de secours gratuite.

## 🧠 Méthodologie
L'algorithme pondère trois axes majeurs :
1. **Facteurs Imprévus** : Blessures de dernière minute, météo, tensions internes.
2. **Forme Dynamique** : Analyse des 5 derniers résultats avec pondération sur la difficulté des adversaires.
3. **Pression Historique** : Historique des confrontations directes (H2H) sur 5 ans.
